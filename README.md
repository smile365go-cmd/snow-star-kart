# Snow Star Kart — Christmas Cup

HTML, CSS, JavaScript로 만든 크리스마스 카트 레이싱 팬 게임입니다. 공식 Nintendo 게임과 관계없는 독립 구현이며 외부 게임 이미지나 오디오 파일을 사용하지 않습니다.

## 실행

`dist/index.html`을 브라우저로 열면 됩니다. 서버나 빌드, 의존성 설치가 필요 없습니다.

- 방향키 위/아래: 가속과 브레이크
- 방향키 좌/우: 조향
- Space: 아이템 사용
- P: 일시정지 및 재개
- 모바일: 화면 터치 버튼

6개 캐릭터 중 1명을 선택해 AI 5명과 3바퀴를 경주합니다. 로켓, 무적 별, 눈보라 아이템과 아이스 부스트, 충돌, 실시간 순위, 결과 화면을 제공합니다. 음악은 시작 버튼을 누른 뒤 Web Audio로 합성됩니다.

정적 웹 호스팅의 배포 폴더는 `dist`입니다. Google Fonts를 불러올 수 없는 환경에서는 기본 글꼴로 실행됩니다.
